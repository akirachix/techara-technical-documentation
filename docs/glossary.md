# Glossary

| Term | Meaning |
|---|---|
| AC | Alternating current; the type of electrical supply represented by the current metering data model. |
| API | Application Programming Interface; the HTTP interface exposed by the FastAPI backend. |
| Battery state of charge (SoC) | The battery's stored-energy level expressed as a percentage of nominal capacity. |
| Baseline demand | Existing site demand before adding the candidate businesses in a scenario. |
| CT clamp | Current transformer clamp used to sense current around a conductor without placing a conventional ammeter in series. |
| Data label | Provenance marker such as observed, user-entered, estimated or simulated. |
| Duty cycle | The pattern or proportion of time equipment operates. |
| ERB | Energy Regulation Board of Zambia. Regulatory references should be checked against current official guidance. |
| Field agent | User role intended to collect business information and support field meter workflows. |
| Fit check | A rules-based assessment of whether a business load can be supported by a selected mini-grid site profile. |
| Flexible load | A load whose timing or operation can be shifted; GridFit's documented workflow does not automatically reschedule loads. |
| GPRS | General Packet Radio Service, a packet-data service associated with GSM cellular networks. |
| kW | Kilowatt, a unit of power (rate of energy transfer). |
| kWh | Kilowatt-hour, a unit of energy. |
| Load shedding | Deliberate interruption of electricity supply to manage insufficient available generation or network capacity. |
| Mini-grid | A local electricity network serving a defined area, typically with its own generation and distribution infrastructure. |
| Mini-grid operator | Organisation responsible for operating a mini-grid and managing its customers and infrastructure. |
| PUE | Productive Use of Energy; use of electricity for income-generating or productive activity. |
| PWA | Progressive Web App; a web application that can be installable and may support offline capabilities when a service worker is implemented. |
| PZEM-004T | A family of AC measurement modules; the proposed device notes refer to the PZEM-004T-100A variant. |
| Safety margin | Configured buffer used by selected rules to flag results that are close to a technical limit. |
| SME | Small and Medium-sized Enterprise. |
| Spare capacity | Estimated site capacity remaining after accounting for baseline demand and the modelled business loads. |
| Startup load | Short-duration power demand when equipment such as a motor starts. |
| Telemetry | Measurements and device status transmitted from a remote device to a receiving system. |
| ZEDSI | Zambia Energy Data / sector-information reference acronym appearing in project notes; confirm the intended expansion and authoritative source before using it in external material. |
